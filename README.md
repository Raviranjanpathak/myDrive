# 📁 MyDrive — Cloud Storage Web App (MERN)

A full-stack cloud storage application where users can create folders, upload files, and manage their data securely. Built using the MERN stack and deployed on Render.

---

## 🚀 Live Demo

* 🌐 Frontend: https://mydrive-1-2yz9.onrender.com
* 🔗 Backend API: https://mydrive-z0ca.onrender.com

---

## ✨ Features

* 🔐 User Authentication (JWT based login/signup)
* 📂 Create Nested Folders
* 📤 Upload Files (Images supported)
* 🗂️ Organized File Management
* 🌙 Dark Mode Support
* 🔄 Persistent Login (Auth state maintained)
* 🌐 Fully Deployed (Frontend + Backend)

---

## 🛠️ Tech Stack

### Frontend

* React.js
* React Router
* Axios
* CSS (Custom Styling)

### Backend

* Node.js
* Express.js
* MongoDB (Atlas)
* JWT Authentication
* Multer (File Upload)

## ⚙️ Installation & Setup (Local)

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/myDrive.git
cd myDrive
```

---

### 2️⃣ Backend Setup

```bash
cd backend
npm install
```

Create `.env` file:

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
```

Run server:

```bash
npm start
```

---

### 3️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
